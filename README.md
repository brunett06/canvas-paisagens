# 🎨 Paisagens em Canvas

Duas paisagens desenhadas com a **API Canvas 2D** do HTML5, feitas como exercício da faculdade (Sistemas de Informação, UGB).

**▶️ Ver online: [dia](https://brunett06.github.io/canvas-paisagens/paisagem.html) · [noite](https://brunett06.github.io/canvas-paisagens/paisagem_noturna.html)**

| Paisagem | O que pratica |
|---|---|
| [☀️ Dia](paisagem.html) | `fillRect`, `strokeRect`, caminhos com `moveTo`/`lineTo` e círculos com `arc` |
| [🌙 Noite](paisagem_noturna.html) | Tudo do anterior, mais `scale()` para trabalhar em outra escala, paleta de cores própria e sombreamento com triângulos sobrepostos |

## Tecnologias
HTML5 · Canvas API · JavaScript

## Como rodar
Abra `paisagem.html` ou `paisagem_noturna.html` no navegador.
